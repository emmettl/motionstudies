A working renderer is not evidence that a city's source path is ready. Before committing to an authored scene, establish that its defining claim can be supported by an obtainable, dated source and a defensible publication path. This register separates unanswered provider questions from ordinary acquisition and validation work.

This pass reviewed all fourteen candidate briefs, inspected public terms and catalogues, checked the existing Tokyo source contract, and retained temporary review copies of selected official documents. It did not register accounts, obtain gated feeds, contact providers or approve a city for publication. Direct retrieval URLs, timestamps and hashes are recorded in [the retrieval record](data-access-review-2026-09-07.json). A successful HTML fetch may be only an application shell; the record distinguishes that from readable evidence. Earlier feed counts and checksums remain dated observations in the city briefs, not fresh measurements from this review.

## The minimum source package before visual implementation

Every city should produce a small, reviewable package containing:

1. **A claim and a bounded scope:** date, hour, geography, operators, modes and exactly what a moving mark represents. Define the fallback if a defining source is missing.
2. **An access receipt:** authoritative dataset and download URLs without credentials; acquisition method; publisher and intermediary; retrieval time; archive and table hashes; source release and validity; credentials stored outside the artifact.
3. **A rights record for each input and output:** exact licence/terms version and retained copy; attribution and modification notice; raw retention and transformed publication conditions; any provider clarification; compatible treatment of database sharing. Code licensing does not relicense data.
4. **An inspection report:** actual table/field inventory, operator coverage, calendar overlap, timezone and after-midnight rules, stable identities, shape matching, missing/ambiguous cases, and a quantified completeness result for the chosen scope.
5. **A transformation record:** compiler commit and parameters, coordinate/vertical reference systems, simplification and interpolation, headway seed, joins and exclusions, uncertainty and output hashes. Preserve annual survey, planning snapshot and service-day dates separately.

Scheduled events, predictions, reported positions, modelled flows, surveys and synthetic fixtures remain different evidence classes. A trip update does not become GPS; a counter does not become a rider; a building model does not establish rail depth. Missing evidence should narrow the opening or remain visible as unknown.
